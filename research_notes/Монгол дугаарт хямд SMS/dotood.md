# Монголын дотоод гарцаар гарах SMS

Судалгааг 2026 оны 10 сарын 14-нд албан ёсны хуудсуудаас хийсэн. Зорилго нь вэбсайт +976, 8 оронтой дугаар (Unitel, Mobicom, Skytel, G-Mobile, ONDO) руу бизнес өөрөө мессеж илгээж (MT) болох эсэх, нийтлэгдсэн үнэ, илгээгчийн нэр, гэрээний алхам. Үнэ байхгүй бол таамаглаагүй.

messagepro.com бол АНУ-ын компани. Түүний центээр илэрхийлсэн үнэ Монголын MessagePro биш тул доор оруулаагүй.

## Аль Монгол бизнес HTTP API-аар гарах SMS илгээдэг вэ?

### Takeaway
Вэбсайтаас хэрэглэгчийн дугаар руу шууд илгээх HTTP API-г албан ёсоор зарласан дотоод үйлчилгээ нь CallPro Text болон Скайтелийн Web2SMS. Юнипей UniSMS нэгдсэн API болон 130001 дугаараас бүх оператор руу илгээнэ гэж бичсэн боловч үнэ нийтлээгүй. Мобиком, Юнител тусгай дугаараас MT илгээх үйлчилгээтэй ч нээлттэй HTTP API-ийн үнэ, баримт бичиг алга. SMS.mn, Мобинет, ONDO, G-Mobile-ийн ийм гарц олдсонгүй.

### Cited Findings
- CallPro Text нь OTP, мэдэгдлийг «өөрийн үндсэн систем, апп-аасаа API-аар» илгээнэ. Багц 2-т API интеграц 2, багц 3-т 4. Масс, түргэн, нэг удаагийн баталгаажуулалт, автомат мессеж илгээнэ. Тайланг үүрэн оператор тус бүрээр задалж харна. — [CallPro Text](https://www.callpro.mn/service/text)
- Англи хуудас: нэг гэрээгээр Монголын болон олон улсын оператор компаниудтай холбогдоно. OTP болон төлөвийн автомат мессеж илгээнэ. — [CallPro Text, English](https://en.callpro.mn/service/text)
- Гуравдагч эх сурвалж (CallPro-ийн өөрийн баримт бичиг биш): erxes төсөл хуучин MessagePro GET дуудлагыг `POST https://api-text.callpro.mn/v1/sms/send` руу сольсон. Толгойд `x-api-key`, биед `from`, `to`, `text`. — [erxes issue 7750](https://github.com/erxes/erxes/issues/7750)
- docs.callpro.mn нээлттэй хуудаснаас SMS илгээх endpoint, үнэ гараагүй. Татсан агуулга нь зөвхөн «CallPro documentation» гарчигтай байсан. — [CallPro documentation](https://docs.callpro.mn/)
- Скайтел Web2SMS: «Мессеж API буюу URL хаяг ашиглан өөр вэб хуудастай холбогдох боломжтой.» Цагт 50,000 хэрэглэгч. Хурал, мэндчилгээ, дотоод мэдээ, төлбөр, зээлийн мэдээлэл илгээнэ. Хуудсан дээр огноо, хувилбар байхгүй. Холбоо барих хаяг нь info@skymass.mn. — [Web2Sms](http://web2sms.skytel.mn/)
- Юнипей UniSMS: нэг интерфейс, нэг API-аар бүх операторын дугаар руу мессеж илгээж, ERP, CRM-тэй холбоно. Илгээгч нь 130001. Сарын бүртгэлийн хураамжгүй, 24/7. Үнэ, endpoint, гэрээний журам хуудсан дээр байхгүй. — [UniSMS](https://www.unipay.mn/sms/)
- Мобиком корпораци: 6 оронтой 13xxxx, 14xxxx, 15xxxx дугаараар SMS MT илгээх, SMS MO хүлээн авах үйлчилгээ. Захиалгыг сайтаар өгнө. Нээлттэй HTTP илгээх API-ийн баримт бичиг энэ хуудсанд байхгүй. — [Мобиком, тусгай дугаар](https://business.mobicom.mn/Mobile%20service/10)
- mobiopenGW нь SMS, USSD зэрэгт интеграц хийх платформыг CAMARA, GSMA стандартаар «хөгжүүлж байна» гэж танилцуулсан. Хайлтад гарсан API лавлагаа нь Text to Speech, Speech to Text-ийг нэрлэсэн бөгөөд SMS илгээх үнэ, endpoint байгаагүй. — [mobiopenGW](https://developer.mobicom.mn/)
- Юнител: тусгай дугаараар байгууллагын зар, мэдээг олон хэрэглэгч рүү зэрэг хүргэнэ. Гэрээний материал шаардана. HTTP API, нэг мессежийн үнэ энэ хуудсанд байхгүй. — [Юнител, тусгай дугаарт мессеж](https://corp.unitel.mn/unitel/QMG1pv/Ighj0O)
- smsnumber.mn нь телевиз, радио, сонин, лавлахын тусгай дугаарт SMS-ээр мэдээлэл хүлээн авах (MO) нөхцөл. 2009 оны 5 сарын 15-ны ХХЗХ-ны шийдвэр, 2009 оны 5 сарын 27-ны санамж бичиг. Вэбээс хэрэглэгч рүү түлхэх HTTP API биш. — [smsnumber.mn](http://www.smsnumber.mn/)
- SMS.mn нэртэй үйлчилгээний албан хуудас олдсонгүй. GitHub дээрх `sms-mn` нь Unitel, Mobicom руу холбох гуравдагч Python сан. Endpoint-ууд нь `YOUR_UNITEL_API_KEY`, `YOUR_MOBICOM_BASE_URL` гэсэн орлуулагч. Үнэ байхгүй. — [Suldee925/sms-mn](https://github.com/Suldee925/sms-mn)
- Мобинетийн одоогийн mobinet.mn дээр байгууллагын SMS API олдсонгүй. phone.mobinet.mn дээрх мессежийн үнэ нь MNP75 хэрэглэгчийн тариф (сүлжээндээ 6₮, Мобиком болон бусад руу 30₮, НӨАТ орсон). Энэ нь вэбсайтын MT гарц биш. — [Мобинет MNP75 тариф](https://phone.mobinet.mn/index.php?page=pricepre)
- ONDO.mn дээр 2026 оны хэрэглэгчийн мэдээ (2026-09-01, 2026-08-11) байгаа ч байгууллагын SMS API, тусгай дугаарын үнэ олдсонгүй. — [ONDO.mn](https://www.ondo.mn/post/)
- G-Mobile-ийн тусдаа MT үнэ, HTTP API-ийн хуудас олдсонгүй. smsnumber.mn-ийн хайлтын текст G-Mobile-ийг Бага тойруу 3/9, утас 98103636 гэж холбосон. Fetch-ийн текстэд гурван хаяг байсан ч операторын нэр бүрэн шошготой үлдсэнгүй. — [smsnumber.mn](http://www.smsnumber.mn/)

### Inferences
- Кинотеатр, вэбсайтын мэдэгдэлд хамгийн ойр бэлэн гарц нь CallPro Text. Албан хуудас нь API, OTP, оператор тус бүрийн тайланг шууд бичсэн.
- Скайтелийн Web2SMS мөн URL API-тай гэж бичсэн. Хуудас огноогүй, имэйл нь хуучин skymass.mn тул 2026 онд хэвээр эсэхийг гэрээгээр баталгаажуулах хэрэгтэй. Энэ нь таамаглал биш, хуудасны шинж тэмдэг.
- Мобиком, Юнителийн тусгай дугаар нь мессеж илгээх бүтээгдэхүүн мөн. Нээлттэй, өөрөө бүртгүүлээд түлхүүр авдаг HTTP API гэж албан хуудас хэлээгүй.

### Gaps
- MessagePro.mn-ийн 2026 оны албан хуудас, үнэ олдсонгүй. Домэйн DNS жагсаалтад `messagepro.mn` гэж харагдсан боловч энэ нь ажиллаж буй SMS үйлчилгээ, үнэ биш. — [robtex, .mn жагсаалт](https://robtex.com/en/dns-lookup/mn/metis)
- SMS.mn, Мобинет, ONDO, G-Mobile-ийн гарах SMS-ийн HTTP API ба нийтлэгдсэн үнэ олдсонгүй.
- CallPro-ийн албан API баримт бичгээс endpoint-ийг баталгаажуулж чадаагүй. Endpoint зөвхөн гуравдагч кодоос.
- Юнител, Мобикомын гэрээний дараах хаалттай HTTP API байж болно. Нээлттэй хуудас үүнийг батлаагүй.

## Нэг SMS-ийн нийтлэгдсэн үнэ хэд вэ?

### Takeaway
Нийтлэгдсэн дотоод үнэ: CallPro нэг мессеж 22₮ (НӨАТ орсон) монгол хуудсан дээр, англи хуудсан дээр 16.5₮ (НӨАТ орсон). Скайтел Web2SMS Скайтел руу 25₮, бусад сүлжээ рүү 55₮. Мобикомын тусгай дугаараас илгээх 45₮ (НӨАТ орсон). Юнител, UniSMS, G-Mobile, ONDO дээр нэг MT мессежийн үнэ нийтлээгүй. CallPro-ийн сарын суурь хураамжийн дүн нийтлээгүй.

### Cited Findings
- CallPro, монгол: «1 мессежний тариф нь 22₮ /НӨАТ орсон/» бөгөөд сарын суурь хураамж дээр тухайн сарын мессежийн тоогоор нэмнэ. Суурь хураамжийн төгрөгийн дүн, багцын сарын үнэ, оператороор ялгаатай үнэ байхгүй. Кирилл 70, латин 160 тэмдэгт. Хэтэрвэл мессеж хуваагдана. Үнийн огноо, хувилбар байхгүй. Хуудсыг 2026-10-14-нд татсан. — [CallPro Text](https://www.callpro.mn/service/text)
- CallPro, англи: «The rate for 1 message is 16.5₮ (VAT included)» мөн сарын суурь хураамж дээр нэмнэ гэсэн. Дүн байхгүй. Огноо байхгүй. Монгол 22₮-тэй зөрүүтэй. — [CallPro Text, English](https://en.callpro.mn/service/text)
- Скайтел Web2SMS нэгж үнэ: Скайтелийн сүлжээнд 25₮, бусад сүлжээнд 55₮. НӨАТ орсон эсэх, сарын хураамж, доод багц энэ хүснэгтэд байхгүй. Огноо байхгүй. — [Web2Sms](http://web2sms.skytel.mn/)
- Скайтелийн телемаркетингийн «Мессеж маркетинг» нь өөр бүтээгдэхүүн. Хүснэгт: 1,000–5,000 хэрэглэгч 22₮, 5,001–30,000 нь 16.5₮, 30,001-ээс дээш 11₮. VIP багана эхний мөрөнд 55₮. Сүлжээ баганад «Скайтел», хэмжих нэгж «1 мессеж». Дараа төлбөртийн багана татсан хүснэгтэд хоосон. «Тусгай дугаар болон тусгай нэрээр илгээх боломжтой.» Нас, хүйс, байршлаар Скайтелийн хэрэглэгч рүү илгээдэг кампанит ажил. Нэг хэрэглэгч рүү OTP илгээх Web2SMS-ийн 25/55₮-тэй андуурч болохгүй. Огноо байхгүй. — [Skytel телемаркетинг](http://web2sms.skytel.mn/testWeb2SmsService.html)
- Мобиком, тусгай дугаараас илгээх: урьдчилсан төлбөрт 45₮, дараа төлбөрт 45₮, НӨАТ багтсан. Бүртгэл: энгийн 99,000₮, хүрэл 220,000₮, мөнгөн 330,000₮, алтан 550,000₮. Сарын хураамж 22,000₮. Барьцаа 66,000₮. Хүлээн авах (MO) тариф: 0, 20, 40, 150, 250, 350, 450, 550₮. «Үнэ тарифт НӨАТ багтсан.» 0₮ мөрөнд эзэмшигч нь хэрэглэгчийн өмнөөс энгийн мессежийн тарифаар төлнө гэсэн тэмдэглэлтэй. Огноо байхгүй. Хуудсыг 2026-10-14-нд татсан. Бусад оператор руу өөр үнэтэй эсэх гэж бичээгүй. — [Мобиком, тусгай дугаар](https://business.mobicom.mn/Mobile%20service/10); давхардсан дэмжлэгийн хуудас — [support.mobicom.mn](https://support.mobicom.mn/mon/sms-based/tusgai-dugaar)
- Юнител тусгай дугаар: бүртгэл 90,000₮–500,000₮, барьцаа 60,000₮, сарын суурь 20,000₮. Дугаарлалт: 13**** банк, 14**** дотоод, 15**** ашиг. Нэг илгээх мессежийн үнэ байхгүй. НӨАТ орсон эсэхийг энэ хуудас хэлээгүй. Огноо байхгүй. — [Юнител](https://corp.unitel.mn/unitel/QMG1pv/Ighj0O)
- smsnumber.mn: бүртгэл, суурь, барьцааг «НӨАТ ороогүй» гэж бичсэн. Энгийн 90,000₮, хүрэл 200,000₮, мөнгөн 300,000₮, алтан 500,000₮, суурь 20,000₮, барьцаа 60,000₮. MO ангилал 150–550 нь «НӨАТ орсон». Орлого: үйлчилгээ эрхлэгч 45%, дугаар эзэмшигч 55%. Журам 2009-05-15, санамж 2009-05-27. Гарах нэг SMS-ийн үнэ байхгүй. — [smsnumber.mn](http://www.smsnumber.mn/)
- UniSMS: «Сар бүрийн бүртгэлийн хураамж төлөхгүй.» Нэг мессежийн үнэ, доод багц, операторын ялгаа байхгүй. — [UniSMS](https://www.unipay.mn/sms/)

### Inferences
- Мобикомын НӨАТ-тай дүн нь smsnumber.mn-ийн НӨАТ-гүй дүнг 10% нэмсэнтэй таарна: 90,000×1.1=99,000, 200,000×1.1=220,000, 300,000×1.1=330,000, 500,000×1.1=550,000, сар 20,000×1.1=22,000, барьцаа 60,000×1.1=66,000. Юнителийн 90,000–500,000, 60,000, 20,000 нь smsnumber-ийн НӨАТ-гүй мөртэй адил боловч Юнител НӨАТ-ыг тэмдэглээгүй. Энэ нь нэгдсэн тусгай дугаарын бүртгэлийн үнэ гэсэн дүгнэлт. Гарах мессежийн 45₮ зөвхөн Мобикомын хуудсанд бий.
- CallPro-ийн нэг үнэ (оператороор задраагүй) нь Unitel, Mobicom, Skytel, G-Mobile, ONDO-д ижил гэж шууд нотлохгүй. Хуудас ялгаатай тариф жагсаагаагүй.
- Хуваагдсан кирилл мессеж тус бүр 22₮ эсэхийг CallPro шууд бичээгүй. «1 мессеж» гэж тарифласан, хэтэрвэл хуваагдана гэсэн анхааруулгатай.

### Gaps
- CallPro-ийн сарын суурь хураамж, багц 1–3-ын сарын үнэ, доод худалдан авалт нийтлээгүй. 22₮ ба 16.5₮-ийн аль нь 2026 оны хүчинтэй үнэ болохыг хуудас заагаагүй.
- Юнителийн нэг MT мессежийн үнэ нийтлээгүй.
- Мобикомын 45₮ бусад операторын дугаар дээр мөн эсэх нийтлээгүй.
- Скайтелийн 25₮ ба 55₮-д НӨАТ орсон эсэх, сарын хураамж нийтлээгүй. Хуудасны огноо байхгүй.
- UniSMS, G-Mobile, ONDO, Мобинет, SMS.mn, MessagePro.mn-ийн нэг SMS-ийн төгрөгийн үнэ олдсонгүй. Таамаглаагүй.
- Олон улсын гарц (Messaggio, Plivo, BudgetSMS, Unimatrix, MoceanAPI / moceansms.mn) евро, ам.доллараар Монгол руу үнэ нийтэлсэн. Эдгээр нь Монголын оператор биш тул энэ тэмдэглэлд үнийг ашиглаагүй.

## Илгээгчийн нэр CinemaFeel байж болох уу?

### Takeaway
CallPro дээр илгээгч нь дугаар. Брэндийг мессежийн төгсгөлд текстээр бичнэ. Юнипей 130001-ээс илгээнэ. Мобиком, Юнител, smsnumber.mn нь 13xxxx, 14xxxx, 15xxxx тоон тусгай дугаар. Скайтелийн мессеж маркетингийн хуудас «тусгай нэр» гэж бичсэн ч CinemaFeel гэсэн үсгэн илгээгчийг батлаагүй. Аль ч албан хуудас CinemaFeel гэсэн alphanumeric sender-ийг зөвшөөрсөн гэж бичээгүй.

### Cited Findings
- CallPro: «Зөвхөн мессеж илгээж буй дугаараар илгээгдэх тул та мессежийн төгсгөлд дуудлага хүлээн авах дугаар болон байгууллагын брэнд нэрийг тусгах боломжтой.» Ашиглах дугаар: 13xxxx, 14xxxx, 15xxxx, мөн IP72. Гар утасны дугаараараа илгээх тухай асуултад эдгээр дугаарыг нэрлэсэн. — [CallPro Text](https://www.callpro.mn/service/text)
- Англи хуудас: «Messages are sent by number only.» Холбоо барих дугаараа мессежийн төгсгөлд оруулахыг зөвлөсөн. — [CallPro Text, English](https://en.callpro.mn/service/text)
- UniSMS: «Тусгай дугаар шаардлаггүй. 130001 тусгай дугаараас мессэж очно.» Өөрийн брэнд нэрээр илгээнэ гээгүй. — [UniSMS](https://www.unipay.mn/sms/)
- Мобиком: илгээгч нь 6 оронтой 13xxxx, 14xxxx, 15xxxx. Үсгэн нэр гээгүй. — [Мобиком](https://business.mobicom.mn/Mobile%20service/10)
- Юнител: 13**** банк, 14**** дотоод хэрэгцээ, 15**** ашгийн зориулалт. Үсгэн нэр гээгүй. — [Юнител](https://corp.unitel.mn/unitel/QMG1pv/Ighj0O)
- Скайтел мессеж маркетинг: «Тусгай дугаар болон тусгай нэрээр илгээх боломжтой.» «Тусгай нэр» нь CinemaFeel мэт үсгэн sender гэж тодорхойлоогүй. Хүснэгтийн сүлжээ нь Скайтел. — [Skytel телемаркетинг](http://web2sms.skytel.mn/testWeb2SmsService.html)
- Web2SMS-ийн нүүр хуудас илгээгчийн нэрийн дүрмийг бичээгүй. — [Web2Sms](http://web2sms.skytel.mn/)
- Гуравдагч PHP код CallPro руу `brand` талбар явуулдаг. Энэ нь CallPro-ийн албан баримт бичиг биш. Албан FAQ нь илгээгч дугаар, брэндийг текстэд бич гэж байна. — [fleetbase CallProSmsService](https://github.com/fleetbase/core-api/blob/main/src/Services/CallProSmsService.php); зөрчилдөж буй албан тайлбар — [CallPro Text](https://www.callpro.mn/service/text)

### Inferences
- CinemaFeel вэбээс илгээхэд хэрэглэгч дээр «CinemaFeel» гэсэн илгээгчийн нэр харагдахгүй. CallPro, UniSMS, Мобиком, Юнител дээр тоон дугаар харагдана. Брэндийг «CinemaFeel» гэж мессежийн биед бичиж болно.
- 15xxxx нь ашгийн дугаар тул кинотеатрын мэдэгдэлд Юнителийн ангиллаар 15**** тал руу ойр. 13**** нь банк. Энэ нь Юнителийн өөрийн ангилал.

### Gaps

## Эхний мессежээс өмнө гэрээ, бүртгэл хэрэгтэй юу?

### Takeaway
Тийм. Нээлттэй хуудсууд дээр карт оруулаад шууд илгээдэг өөрөө үйлчлэх бүртгэл алга. CallPro нэг удаа гэрээ байгуулна. Скайтел дээр биеэр, имэйлээр эсвэл утсаар шинэ хэрэглэгч болно. Юнител албан бичиг, өргөдөл, гэрчилгээ, төлбөрийн баримт шаардана. Мобиком захиалга өгнө. smsnumber.mn нь 2009 оны нэгдсэн журмаар өргөдөл, албан бичиг шаардана.

### Cited Findings
- CallPro англи FAQ: үйлчилгээ эхлүүлэхэд борлуулалтын менежертэй холбогдож нэг удаа гэрээ байгуулна. Админ эрхийг бүртгэлтэй имэйлээс info@callpro.mn руу хүснэ. — [CallPro Text, English](https://en.callpro.mn/service/text)
- CallPro монгол FAQ «Үйлчилгээг эхлүүлэхийн тулд яах ёстой вэ?» гэсэн асуулттай боловч 2026-10-14-нд татсан хуудсанд хариултын текст байгаагүй. Админ эрх: info@callpro.mn руу бүртгэлтэй мэйлээс. — [CallPro Text](https://www.callpro.mn/service/text)
- Скайтел шинэ хэрэглэгч: Скайтел плазад биеэр, info@skymass.mn, эсвэл телемаркетингийн мэргэжилтэн рүү утаснаар. — [Web2Sms](http://web2sms.skytel.mn/)
- Юнител гэрээний материал: байгууллагын албан хүсэлт, www.smsnumber.mn дээрх өргөдөл, улсын бүртгэлийн гэрчилгээний хуулбар, төлбөр тушаасан баримт. — [Юнител](https://corp.unitel.mn/unitel/QMG1pv/Ighj0O)
- Мобиком: шинэ хэрэглэгч сайтын баруун дээд булангаар захиалга өгнө. Дэлгэрэнгүйг онлайн туслахаар авна. Хэрэглээний тайланг мөн чатаар. — [Мобиком](https://business.mobicom.mn/Mobile%20service/10)
- smsnumber.mn бүрдүүлэх материал: өргөдөл, албан бичгээр хүсэлт, үйл ажиллагааны туршлага, аж ахуйн нэгжийн гэрчилгээний хуулбар, төлбөрийн баримт. Журам 2009-05-15. — [smsnumber.mn](http://www.smsnumber.mn/)

### Inferences
- Вэбсайт эхний мессежээ илгээхийн өмнө байгууллага гэрээ, тусгай дугаар эсвэл CallPro/Скайтелийн бүртгэлгүйгээр шууд HTTP дуудлага хийх нөхцөл нийтлэгдсэн хуудсуудад байхгүй.
- Тусгай дугаар авах нь операторын бүртгэл. CallPro тэр дугаараар илгээнэ гэж өөрийн FAQ-д бичсэн тул CallPro-ийн гэрээ нь тусгай дугаартай холбоотой байж болно. CallPro өөрөө операторын өргөдлийн жагсаалтыг давтаагүй.

### Gaps
- CallPro-ийн монгол хуудас гэрээний хариуг хоосон үлдээсэн. Гэрээний дүгнэлт нь англи FAQ-аас.
- CallPro гэрээ нь ХХЗХ-ны тусгай дугаарын өргөдлийг орлох уу, давхар шаардах уу гэдэг албан текст олдсонгүй.
- UniSMS-д гэрээ байгуулах эсэх, 130001-ийг хуваалцсан дугаар мөн эсэхийг дэлгэрүүлсэн журам олдсонгүй.
- ONDO, G-Mobile, Мобинет, SMS.mn дээр бүртгэлийн алхам олдсонгүй.
